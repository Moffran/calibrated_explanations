# Independent CE project website

This site is a neutral project introduction, not a company homepage. Calibrated Explanations remains an independent, BSD 3-Clause open-source project.

## Publish
1. Review and merge this change through the official Moffran repository.
2. A repository administrator enables **Settings → Pages → Source: GitHub Actions**.
3. Run `Publish CE project site` (or allow the push-triggered workflow).
4. Verify the resulting Pages deployment URL before linking to it as live.
5. Optionally set the repository About > Website link to the verified Pages URL.

The *anticipated* default URL is `https://moffran.github.io/calibrated_explanations/`, but this is not verified until GitHub Pages is activated.

Do not change the canonical PyPI/Read the Docs location or BSD-3-Clause license. Grejna is a separate commercial-services link; the demo is a research-oriented resource hosted at JU.

## Quality
Standalone semantic HTML and CSS, no framework/runtime dependencies. Test mobile layout, keyboard focus, text wrapping and link destinations. All numerical display values are explicitly illustrative.
