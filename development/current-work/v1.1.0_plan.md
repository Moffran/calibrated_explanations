# v1.1.0 Plan

> **Release version:** `1.1.0`
> **Development version:** `1.1.0-dev`
> **Status:** Active
> **Theme:** Narrative semantic contract and contract consolidation

## Outcome

Adds the minimal ADR-041 narrative semantic contract: an additive
`metadata.narrative_context` in serialized explanations and a deterministic,
immutable `NarrativeSpec` built from them, while the existing offline template
narration and its public API stay unchanged. The release also implements the
canonical ranking contract accepted in v1.0.2 (ADR-042), represents one-sided CPS interval endpoints as unbounded,
turns the v1.0.2 unrecognised-token warning into a `ConfigurationError`,
graduates two experimental call-time parameters to typed arguments, redacts
sensitive values in governance events, unifies plugin validation in the CLI and
deprecates the root `transform_to_numeric` export. As a minor release it may
change rule/feature ordering, open interval endpoints and the handling of
invalid `CE_*` tokens; each change is announced in `CHANGELOG.md` with
migration notes.

## Excluded

- Narrative provider plugin family, provider registry and dispatch, provider
  configuration and public provider API, and verification of provider prose
  (ADR-041 D7).
- Re-expressing the template engine over `NarrativeSpec` (ADR-041 D6).
- Changing calibration or interval algorithms beyond the T10 endpoint
  representation.
- Removing `transform_to_numeric` from the root namespace; T15 only deprecates
  it, and removal follows the ADR-011 timeline.
- Caching/parallel on-by-default graduation; both remain explicitly opt-in.
- New explanation types or modalities.

## Dependencies

- Narrative chain: T1 blocks T2-T4 and T6; T3 blocks T4.
- T4 carries its own ADR-042 ordering until T9 lands; T9 makes
  `build_narrative_spec` delegate to the single ranking implementation (ADR-042
  D9) and applies ADR-042 D16 to template narration, which changes T6 output
  deliberately.
- T4 marks open (infinite-percentile) endpoints unbounded; T10 changes their
  reported values, not the flags. `to_json()` of off-centre one-sided queries
  such as `(-inf, 40)` still fails its serialization invariant check; resolve
  with T10.
- T11 removes or updates the `check_warning_policy.py` entry added for #219 in
  v1.0.2.
- T15's prerequisite #202 (wrapper auto-encoding) closed in v1.0.1.

## Release-specific gates

- ADR-041 is `Accepted` in `development/adrs/` (T1).
- The base install gains no new runtime dependency and narration needs no
  network access (T2-T6).
- `to_json()` payloads are unchanged apart from the added
  `metadata.narrative_context`; payloads without it still load and build a
  spec (T2, T4).
- Default template narration output is unchanged except for ordering changes
  required by ADR-042 (T6, T9).
- Ordering changes from T9 and the unbounded endpoints from T10 are listed in
  `CHANGELOG.md` with migration notes, and the v1.0.x characterisation tests
  are updated deliberately rather than deleted.
- Serialized explanations with unbounded endpoints round-trip, and plots render
  them without errors (T10).
- The T15 deprecation appears in the active-deprecations report with a removal
  target.
- `make capability-chain-check` passes.
- Standard repository gates (tests, lint, docs build, version alignment) are
  owned by `release.md` and `make release-preflight`; not repeated here.

## Release decision

`Not ready` — T1-T4 and T6 are done; T9-T15 have not started.
